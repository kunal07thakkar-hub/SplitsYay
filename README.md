# SplitsYay

SplitsYay is an expense-sharing app made using Kotlin Multiplatform. It is being developed to make splitting bills and managing shared expenses among friends easier.

## Technologies Used
- Kotlin
- Compose Multiplatform
- Android Studio
- GitHub

## Current Progress
- Welcome screen
- Login and sign-up screens
- Navigation between screens
- Basic form validation

## Planned Features
- User authentication
- Create groups
- Add and split expenses
- Track payments
- SmartSettle

## Project Structure
- `androidApp` – Android app
- `iosApp` – iOS app
- `shared` – Shared application code
